# Fundamentos de Programación

Repositorio dedicado a las prácticas y ejercicios de la asignatura Fundamentos de Programación. Aquí se documenta el flujo de trabajo lógico desde el diseño de algoritmos hasta su implementación en código.

---

## Herramientas y Entorno

* **DFD (Diagrama de Flujo de Datos):** Modelado, representación visual y trazado de lógica algorítmica.
* **Visual Studio Code:** Entorno de desarrollo principal utilizado para la escritura, estructuración y ejecución del código fuente.
* **Inteligencia Artificial:** Uso de herramientas de IA como asistente para facilitar el desarrollo de las actividades, optimización de lógica, depuración de errores y comprensión de conceptos clave.
